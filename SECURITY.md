# Security Policy

## Supported Versions

logging4s follows semantic versioning. Only the latest published release is supported; there is no
back-porting of fixes to older release lines at this stage.

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, use [GitHub Security Advisories](https://github.com/logging4s/logging4s/security/advisories/new)
to report privately, or email **shadowsmind.dev@gmail.com** with details and, if possible, a minimal
reproduction.

You should expect an acknowledgement within a few days. Once a fix is available, we'll coordinate on
disclosure timing and credit before making anything public.
